# esports_individuals

Proyecto base para la página web de esports_individuals.

## Descripción
Este repositorio está preparado para servir como punto de inicio para una landing page o sitio web relacionado con jugadores, torneos y contenido de esports.

## Archivos principales
- `index.html`: página principal del sitio.

## Uso
1. Abre `index.html` en tu navegador para ver la vista inicial.
2. Si quieres servirlo localmente, también puedes usar un servidor estático simple como:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.
